# FinTrack

A full-stack financial and investment portfolio platform built with C#, ASP.NET Core, Angular, PostgreSQL, and AI.

## Overview

FinTrack is a full-stack web application designed to help users track investment portfolios, monitor market data, manage transactions, and analyze portfolio performance.

The project is being developed to demonstrate modern software engineering practices including RESTful API development, relational database design, authentication, third-party API integration, AI integration, and containerization.
